# CSS Challenge

## Project Overview

This project is a CSS Challenge created to practice modern CSS layout and animation techniques. It includes Flexbox, CSS Grid, responsive design, and a smooth CSS animation component.

## Objective

To improve practical CSS skills by creating responsive layouts using Flexbox and CSS Grid, along with a simple professional animation.

## Technologies Used

- HTML5
- CSS3

## Challenges Included

### 1. Flexbox Layout
- Three cards arranged in a row on desktop.
- Cards stack vertically on smaller screens.
- Uses Flexbox properties such as `justify-content`, `align-items`, and `gap`.
- Includes hover effects.

### 2. CSS Grid Layout
- Gallery/dashboard-style grid layout.
- Includes at least six grid items.
- Uses responsive grid columns and spacing.
- Rearranges responsively on smaller screens.

### 3. CSS Animation
- Includes a smooth CSS animation/interaction.
- Uses CSS `transition`, `transform`, or keyframes.
- Animation is designed to be subtle and user-friendly.
